4. 공공데이터 API를 이용한 기능에 대한 안내

본 프로젝트는 한국관광공사 국문 관광정보 서비스 API(공공데이터포털 data.go.kr 제공)를 활용하여 다양한 관광 정보를 제공하고 사용자 맞춤형 여행 코스를 생성할 수 있는 기능을 구현하였습니다.

먼저, 사용자가 선택한 여행 테마(웰니스 힐링, 반려동물 동반, 한류/전통 체험, 미식 여행, 문화 탐방, 자연 여행)에 따라 지역기반 관광정보 조회 API(areaBasedList2)를 호출하여 테마에 적합한 컨텐츠 타입의 관광지 목록을 자동으로 추천합니다. 예를 들어, 미식 여행 테마를 선택하면 음식점과 관광지 컨텐츠 타입을 조합하여 관련 장소들을 추천하고, 한류/전통 체험 테마의 경우 문화시설, 축제/행사, 관광지를 함께 조회하여 통합된 추천 목록을 제공합니다.

장소 목록 페이지에서는 지역기반 관광정보 조회 API를 활용하여 관광지, 문화시설, 음식점, 숙박, 축제/행사, 레포츠 등 다양한 카테고리별로 장소를 조회할 수 있으며, 키워드 검색 API(searchKeyword2)를 통해 장소명이나 주소로 검색할 수 있습니다. 모든 목록은 페이지네이션을 지원하여 20개씩 페이지 단위로 조회되며, 사용자는 원하는 장소를 선택하여 나만의 여행 코스에 추가할 수 있습니다.

장소 상세 페이지에서는 공통정보 조회 API(detailCommon2)를 통해 해당 장소의 기본 정보인 제목, 주소, 전화번호, 홈페이지, 개요, 좌표 등을 조회하고, 소개정보 조회 API(detailIntro2)를 통해 운영시간, 휴무일, 주차 정보, 반려동물 동반 가능 여부 등 상세 운영 정보를 제공합니다. 또한 이미지정보 조회 API(detailImage2)를 활용하여 해당 장소의 다중 이미지를 갤러리 형태로 표시하며, 공통정보에서 제공하는 좌표 데이터를 활용하여 카카오맵에 장소 위치를 표시합니다.

추천 코스 페이지와 장소 목록 페이지에서는 선택한 장소들의 좌표 정보를 활용하여 카카오맵에 다중 마커를 표시하고, 사용자가 선택한 장소들 간의 경로를 연결하여 시각적으로 확인할 수 있습니다. 또한 지도 위의 마커를 클릭하면 해당 장소를 코스에 추가하거나 제거할 수 있는 인터랙티브한 기능을 제공합니다.

반려동물 동반 테마를 선택한 경우, 반려동물 동반 여행정보 조회 API(detailPetTour2)를 활용하여 반려동물과 함께 방문할 수 있는 장소 정보를 제공하며, 한류/전통 체험 테마에서는 행사정보 조회 API(searchFestival2)를 통해 지역별 축제 및 행사 정보를 함께 조회하여 더 풍부한 여행 정보를 제공합니다.

사용자가 추천된 장소들을 선택하여 여행 코스를 생성할 때, 선택한 장소들의 정보(제목, 주소, 이미지, 좌표 등)는 Firebase에 저장되며, 이 과정에서 API에서 제공받은 원본 데이터가 그대로 저장되어 다국어 환경에서도 원본 정보를 유지할 수 있습니다. 생성된 코스는 코스 상세 페이지에서 다시 조회되며, 저장된 좌표 정보를 기반으로 지도에 모든 장소를 표시하고 장소 간 거리를 계산하여 총 여행 거리를 제공합니다.

모든 API 호출은 Axios를 통해 이루어지며, 개발 환경에서는 Vite 프록시를 사용하여 CORS 이슈를 해결하고, 프로덕션 환경에서는 공공데이터포털의 직접 URL을 사용합니다. API 호출 실패 시 사용자에게 적절한 오류 메시지를 표시하고 재시도 기능을 제공하며, 로딩 중에는 Skeleton UI를 통해 사용자 경험을 개선합니다.
